  信号 A&B 同时成立”后归档（约 4.15s，序号 001）；同名再下序号 002 不覆盖；

## 4. 缺陷与遗留

- 本次未发现致命（数据错误/误操作）或严重（流程中断）缺陷；开发过程中发现并修复
  的问题（执行作业外键登记顺序、OCR find_text 返回解包、单步许可与暂停唤醒事件
  串用、配置目录 property 调用、t_export_file 误用 id 列等）均已回归验证。
- 已知范围限制（非缺陷，与开发文档一致）：
  - 图片型（扫描件）PDF 的 OCR 解析为二期能力，当前仅支持带文本层 PDF；
  - PyInstaller 不支持跨平台交叉打包，Windows 可执行文件需在 Windows 机用
    `build/build.bat` 构建，本次 Linux 环境交付源码 + Linux 构建脚本/产物；
  - GUI 系统级 XTest 注入在 Xvfb 受限于 libxcb-cursor 运行库，已用 Qt offscreen
    完成界面与业务全链路验证；目标 X11/Windows 桌面具备完整捕获注入能力。

## 5. 验收前检查建议（院方）

1. 在 HIS 测试环境用只读账号 + 脱敏数据执行一次真实作业，人工核对导出文件与
   t_report_record 数据（金额、日期、行数、脱敏展示）；
2. 确认静默下载目录、双信号命中率与超时阈值符合现场网络；
3. 断网状态下复跑一次，确认无外联、功能正常；
4. 触发一次急停，确认 1 秒内停止并释放键鼠；
5. 导出审计报告确认日志哈希链“完整”。
