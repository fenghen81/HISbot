# 部署手册

适用：医院内网现场部署 HISBot（Windows 10/11 或 Linux X11）。部署前须经院方信息科
安全评审，核查账号权限、目录范围与数据字段清单。

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11；或 Linux X11（**不支持 Wayland**） |
| Python | 3.11 或 3.12（源码方式运行时） |
| 分辨率 | 默认 1920×1080，须与站点模板一致 |
| 显示缩放 | **必须 100%**（启动强校验，不符即中止 SCA-001/002） |
| 显示协议 | Linux 必须 X11；检测到 Wayland 拒绝运行 |
| 网络 | 可完全断网；程序无任何外网通信 |
| HIS | B/S、Chrome/Edge/Firefox，自动化账号为**只读账号**（仅查询/导出，无写/审/删权限） |

## 2. 浏览器侧一次性设置（人工完成，程序不修改浏览器）

- 关闭“下载前询问每个文件的保存位置”，使用**静默下载**；
- 默认下载目录固定不变，并在“配置页 → 下载监听目录”填写同一路径；
- 关闭“下载完成后自动打开”；
- 为自动化账号关闭登录验证码（`site.yaml: login.captcha=none`）。

## 3. 安装（源码方式）

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

注意：OpenCV 必须为 `opencv-python-headless`，切勿再装非 headless 的 `opencv-python`；
`numpy` 锁定 1.26.x，否则 rapidocr-onnxruntime 可能异常。

## 4. 初始化

```bash
python tools/migrate.py --root .          # 生成 data/、app.db 与全部表
python -m hisbot.app.main --root .        # 启动
```

首次启动自动生成 `data/`（downloads/archive/quarantine）、`logs/`、`snapshots/`、
`config/master.key`（数据库主密钥，权限 600）与凭据加密文件。**请妥善备份
`master.key` 与 `config/credentials.enc`，丢失主密钥将无法解密历史密文。**

启动顺序与自检：
1. 显示环境校验（缩放/分辨率/X11），不通过弹窗并退出；
2. 数据库初始化、凭据库就绪（Windows 用系统凭据链，无 Secret Service 的
   Linux 自动降级为机器绑定 FileVault：PBKDF2-HMAC 20 万次 + AES-GCM）；
3. 进入主界面。

## 5. 上线步骤（与开发文档 9.2 一致）

1. 准备：确认缩放 100%、浏览器静默下载、记录默认下载目录；
2. 分发：单目录拷贝到目标机（建议 `D:\HISBot` 或 `/opt/hisbot`）；
3. 初始化：导入初始配置（站点、关键词、黑名单）；
4. 凭据录入：配置页录入 HIS 账号口令（加密保存）；
5. 扫描：只读账号执行一次全量扫描生成导航图；
6. 审核：业务审核员勾选路径、标注导出目标、知悉危险点后签发；
7. 试运行：完整执行一次，人工核对导出文件与入库数据；
8. 正式启用：配置定时任务（cron + 工作时间窗），转入无人值守。

## 6. 打包为可执行程序（可选）

PyInstaller **不能跨平台打包**：Windows 版在 Windows 机构建，Linux 版在 Linux 机构建。

```bash
# Linux
bash build/build.sh
# Windows（cmd）
build\build.bat
```

产物为单目录 `dist/HISBot/`（含可执行文件、`_internal`、`config`、`sql`、`tools`），
拷贝到同平台目标机即可运行。首次运行仍会在该目录初始化 data/logs 等。
分发包不含 `master.key`、`credentials.enc` 与任何真实数据，各机首次运行自行生成。

## 7. 显示环境常见问题

- 弹窗提示缩放不符：系统显示设置 → 缩放改 100% → 重启程序；
- Linux 提示 Wayland：登录界面选择 “GNOME on Xorg” / 设置
  `XDG_SESSION_TYPE=x11`，或 `export QT_QPA_PLATFORM=xcb` 后于 X11 会话运行；
- 分辨率不符：按站点模板调整物理分辨率，或在 `config/site.yaml` 修改
  `scale.expected_resolution` 与 `mismatch_policy`（生产建议保持 abort）。
