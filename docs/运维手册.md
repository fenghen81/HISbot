# 运维手册

## 1. 日常维护节奏

| 周期 | 事项 |
|---|---|
| 每日 | 查看作业运行结果、失败告警、磁盘占用；确认定时作业按时执行 |
| 每周 | 检查模板命中率，更新命中率低于 80% 的模板 |
| 每月 | 清理超期日志/截图、执行数据库 VACUUM 与备份（`tools/migrate.py --vacuum`） |
| 变更时 | HIS 界面改版后必须**重新扫描 + 重新审核签发**，禁止沿用旧导航图 |

## 2. 数据生命周期（默认，可在配置调整）

- 业务数据：保留 3 年，超期归档/删除，删除记入审计；
- 操作日志：保留 90 天；普通截图 30 天；异常现场快照 180 天；
- 归档导出文件：保留 1 年。

## 3. 备份

- 数据库每日增量备份（`data/app.db`，含 WAL 时一并备份 `app.db-wal`/`app.db-shm`，
  或备份前触发 checkpoint）；
- `config/`（含 mappings/jobs/graph/keywords/site/app）纳入版本管理；
- **必须独立备份 `config/master.key`**：主密钥丢失则历史密文不可恢复；
  `master.key` 与数据库应分开存放，禁止随程序包外发；
- 模板库 `templates/` 随配置一并备份。

## 4. 一键诊断包

```bash
python tools/dump_diag.py --root .
# 生成 diag/hisbot_diag_YYYYMMDD_HHMMSS.zip
```

包含：运行环境与显示校验、配置（自动脱敏，**不含 credentials.enc/master.key
内容与口令**）、数据库表行数与最近告警/运行、操作日志哈希链校验结果、目录占用。
提交问题给支持人员时附上该 zip。

## 5. 数据库迁移

```bash
python tools/migrate.py --root .            # 初始化/升级，幂等可重复
python tools/migrate.py --root . --vacuum   # 月度维护：回收空间
```

独立建表脚本见 `sql/schema_sqlite.sql`（SQLite 3.35+，可直接执行，15 张表）。

## 6. 看门狗与现场快照

- 独立看门狗线程监控执行心跳，超过 **3 分钟**无心跳判定卡死（SYS-002）：
  记录日志、自动触发急停安全停止、保存现场快照并产生 CRITICAL 告警；
- ERROR 及以上异常自动打包：当前全屏截图、元素信息、最近日志，
  存于 `snapshots/snap_* / watchdog_*`，可在审计页随告警查看。

## 7. 常见故障与处置（错误码）

| 错误码 | 含义 | 自动行为 / 处置 |
|---|---|---|
| SCA-001/002 | 缩放/分辨率与模板不符 | 启动中止；改为 100% 缩放、匹配分辨率后重启 |
| AUT-004 | Wayland 会话 | 切换 X11 |
| LOG-001/002 | 登录失败 / 会话失效 | 按表 14 有限重试；仍失败转人工，核对只读账号/验证码 |
| DET-001/002 | 元素定位失败 | OCR→模板→人工三级定位，重试 1/2/4s；全失败不盲点 |
| EXE-001 | 路径未审核批准 | 拒绝执行；回到审核页签发 |
| EXE-002 | 作业配置签名校验失败（被篡改） | 拒绝执行；用未篡改的已签发配置 |
| EXE-003/004 | 点击失效 / 页面未跳转 | 有限重试与重走；超限停止告警 |
| SCN-002/NAV-004 | 回退连续失败 | 停止扫描/执行，保存现场 |
| SCN-003 | 命中危险元素 | 永不点击，拦截并告警 |
| DLD-001 | 仅临时文件（下载中途取消） | 重新导出，重试 5/10s |
| DLD-002 | 文件稳定但无完成提示，超时 | 按配置重试或失败，不做无证据归档 |
| DLD-003 | 文件数/文件名不符预期 | 重试；超限转人工 |
| DLD-004 | 文件头魔数与扩展名不符 | 文件移入 `quarantine/`，告警，不解析 |
| DLD-006/007 | 归档移动失败 / 下载目录不可用 | 停止告警，检查磁盘与目录权限 |
| PRS-001/002 | 解析坏行超阈值 / PDF 无文本层 | **不重试**，转人工；图片型 PDF 属二期范围 |
| DBS-001/002 | 入库锁/约束失败 | 有限重试；仍失败整批回滚并告警 |
| SYS-002 | 看门狗心跳超时 | 自动急停 + 快照 + CRITICAL 告警 |

通用处置：先用 `dump_diag.py` 取诊断包；核对最近一次导航图是否与当前 HIS 一致；
必要时重新扫描审核。重试耗尽属预期“故障安全”行为，不应通过反复手工干预强行继续。

## 8. 安全巡检清单

- [ ] 自动化账号在 HIS/数据库侧确为只读（无写/审/删权限）；
- [ ] 程序目录与 `app.db`、`credentials.enc`、`master.key` 权限为仅当前用户可读写；
- [ ] 数据库/归档文件未通过任何方式带离院内网络；
- [ ] 机器无外网访问需求，确认程序无外联（可断网运行）；
- [ ] 字段映射中未声明的敏感列确实被丢弃（数据查看页无多余敏感字段）；
- [ ] 操作日志哈希链校验为“完整”。
