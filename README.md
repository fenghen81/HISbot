# HIS 离线数据采集工具（HISBot）

以“外部观察者 + 虚拟操作员”方式，对院内 **B/S 架构 HIS 报表模块** 做只读自动化：
自动登录 → 只读扫描建导航图 → 人工审核签发路径 → 自动导航并点击导出 →
**静默下载双信号落盘确认** → Excel/CSV/PDF 解析 → 敏感字段加密脱敏后幂等入库。
全程断网运行、全程留痕、危险操作永不点击，适配医院内网安全评审。

- 语言/界面：Python 3.11 / 3.12，PySide6 原生桌面 GUI，全中文
- 平台：Windows 10/11（X11 等价能力）、Linux X11（Wayland 拒绝运行）
- 数据库：SQLite 单文件（敏感列 AES-256-GCM 密文 + 脱敏值 + HMAC 检索索引）

---

## 一、五层架构

| 层 | 包 | 职责 |
|---|---|---|
| L1 平台适配 | `hisbot.platform` | 屏幕捕获、键鼠注入、窗口管理、文件监听、凭据库（Win/ Linux 自动选择） |
| L2 感知识别 | `hisbot.perception` | 形状控件检测 + OCR、模板匹配、页面指纹、下载提示识别、三级定位 |
| L3 流程引擎 | `hisbot.scan` / `review` / `execute` | 只读扫描、审核签发、执行状态机、重试策略 |
| L4 数据处理 | `hisbot.download` / `parse` / `store` | 双信号下载捕获、文件解析清洗、加密脱敏、幂等仓储 |
| L5 展现层 | `hisbot.ui` | 六页 GUI、实时镜像、日志、进度、暂停/单步/急停 |

横切：`hisbot.audit`（防篡改哈希链日志 / 告警 / 现场快照 / 3 分钟看门狗）、
`hisbot.schedule`（APScheduler 定时、单执行槽互斥、工作时间窗）。

## 二、核心安全机制

- **只读三重约束**：扫描/执行阶段危险元素（删除/作废/清空等黑名单）只登记、**永不点击**；
  只走审核通过的白名单路径；只读账号在数据库层无写权限兜底。
- **配置防篡改**：作业配置签发时计算 SHA-256（含审核人/时间/版本），执行前校验，
  任一字段被改即拒绝（EXE-002）。
- **静默下载双信号与门**：界面“下载完成”提示（信号 A，连续 2 帧 OCR 命中）
  **且** 文件连续 3 次采样大小不变 + 独占可打开 + 文件头魔数一致（信号 B），
  两者同时成立才归档；伪装文件移入隔离区（DLD-004）。
- **数据最小化**：字段映射中未声明的敏感列直接丢弃；敏感列 `_enc` 密文存储、
  `_mask` 脱敏展示、`_hmac` 仅用于精确检索；界面默认只显示脱敏值。
- **故障安全**：急停检查周期 50ms，点击立即释放键鼠、1 秒内停止且不弹确认框；
  不确定即停止告警；看门狗检测执行线程 3 分钟无心跳自动安全停止。
- **全程留痕**：每次点击/落盘/入库写入操作日志，日志为仅追加 SHA-256 哈希链，
  任何插入、删除、篡改都会在校验时暴露；数据可追溯到作业/运行实例/来源文件/源行号。
- **断网运行**：程序不含任何外网通信代码，凭据用系统凭据链或机器绑定 FileVault 加密。

## 三、快速开始

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 初始化数据库（生成 data/ 目录与表）
python tools/migrate.py --root .

# 启动图形界面
python -m hisbot.app.main --root .
```

启动时自动做显示环境校验：缩放必须 100%、分辨率须与站点模板一致（默认 1920×1080）、
Linux 必须为 X11（Wayland 直接拒绝）。不通过时不允许进入自动化。

无真实 HIS 时可在“作业管理”页勾选 **仿真模式**，用内置仿真 HIS 完成全流程演练；
也可单独启动仿真 HIS 窗口做真机 XTest 演示：

```bash
python -m hisbot.simulator.app --watch ./data/downloads
```

## 四、典型使用流程

1. **配置页**：录入站点、下载目录、超时、关键词/黑名单，保存 HIS 账号凭据（加密）。
2. **作业管理页 → 只读扫描**：自动遍历生成导航图（危险点登记、断点可续扫）。
3. **导航图审核页**：选择目标页与导出按钮 → 自动规划路径并逐边批准 →
   知悉危险点 → 选择字段映射 → 审核并签发（SHA-256 签名）。
4. **作业管理页 → 立即执行**（或加入定时调度）：运行监控页实时查看镜像红框、日志、进度，
   可随时 暂停 / 单步 / 继续 / 急停（快捷键：空格暂停、Esc 急停）。
5. **数据查看页**：默认脱敏预览入库结果、批次质量与文件血缘，可导出脱敏 CSV。
6. **审计页**：按级别/时间筛选操作日志、确认告警、一键导出审计报告并校验日志哈希链。

## 五、测试

```bash
# 确定性单元/集成测试（不依赖 OCR，秒级）
python -m pytest tests -m "not integration" -q

# 含 OCR 的端到端测试（执行全链路 + 扫描建图，约 1~2 分钟）
python -m pytest tests -q
```

当前共 48 个用例：核心算法、加密脱敏与幂等入库、下载魔数/稳定/归档、解析与数据最小化、
重试策略、运行控制、配置签发篡改检测、日志哈希链/看门狗、调度互斥，以及 2 个 OCR 端到端用例。

## 六、目录结构

```
hisbot/
├── src/hisbot/            # 源码（五层 + 横切）
├── config/                # app/site/keywords 配置、mappings、jobs、graph
├── sql/schema_sqlite.sql  # 独立建表脚本（附录 A，可直接执行）
├── tools/migrate.py       # 数据库初始化/迁移
├── tools/dump_diag.py     # 一键诊断包（脱敏打包）
├── tests/                 # pytest 套件
├── docs/                  # 部署 / 用户 / 运维手册
└── requirements.txt
```
运行后生成 `data/`（app.db、archive、quarantine、downloads）、`logs/`、`snapshots/`、`diag/`。

## 七、打包

## 八、范围与限制（与开发文档一致）

- 仅支持**带文本层** PDF 的表格抽取；图片型（扫描件）PDF 的 OCR 解析列为二期。
- 一套键鼠同一时刻只执行一个作业（调度层全局单执行槽互斥）。
- 不修改 HIS 任何数据，不访问下载目录以外的用户目录，不发起任何网络请求。
- HIS 界面改版后必须重新扫描与审核，禁止沿用旧导航图。
